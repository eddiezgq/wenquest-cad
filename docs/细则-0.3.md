状态：**交给 freecad-ai-parts 的会话做**（Eddie 2026-11-17 定：由有零件库修改权限的那个窗口负责）。本文是方向草稿，由那边写进 freecad-ai-parts 的 `docs/plan.md` 与 ADR、经 Eddie 确认后施工；问渠 CAD 这边只负责在 Eddie 电脑上装新版工作台（重跑 `ai-wqcad.ps1`，改固定提交）与验收。

## 决定（Eddie 2026-11-17）

1. **零件库是问渠 CAD 下一步的重点**，目标是“企业用 AI 快速建立自己的零件库”。
2. **先做缝纫机企业**（以 JUKI DDL-9000C 一类的工业直驱平缝机为对象），机器人企业第二个做（同一套工具，机器人关节的数据已有）。
3. **数据先自己从网上找**：没有真实企业的资料前，用公开资料搭一个“示范缝纫机企业（虚构）”的企业库。企业名、物料表是虚构的并明确标注；零件参数只来自登记过、核过条款的公开资料，缺数据就不写。
4. **在 freecad-ai-parts 里做，由那边的会话负责**（零件库代码在那边）。按那边的规矩做——一次一个 issue、分支 `m<阶段>/<简述>`、走 PR、schema 改动单独成 PR 并附 ADR、不改 `tests/golden/` 的预期。PR 由 Eddie 合并。
   - 注意：另一个会话正在那个仓库做 M39、M40（11-17 当天还有提交）。开工时以最新的 main 为准，阶段号接在最新之后，只动零件库相关的文件，避免冲突。

## 为什么先做缝纫机

- 台州是缝纫机产业集中地，企业对口。
- freecad-ai-parts 已有平缝机的应用例（`examples/apps/out/lockstitch/`），它卡住的地方正是零件库缺数据：
  - 选型上限这条路失败，原因是“库里最大的驱动器 SGD7S-2R8A 带不动，要补更大驱动器的数据”；
  - “零件库也没有轴承”，数字孪生无零件可算；
  - 自制件（上轴 LS-101 等）不在零件库里。
- 补上这些，平缝机的例子就能从“失败 / 待确认”变成有结论，验收有明确的对照。

## 0.3b 企业快速建库

### 三条进料通道（企业手里现成的资料）

| 通道 | 输入 | AI 做什么 | 代码做什么 | 人做什么 |
| --- | --- | --- | --- | --- |
| A. 规格书（已有，扩充） | 厂商 PDF / Excel 产品目录 | 一份目录里**整张型号表成批抽取**（现在是一次一个型号） | 按 schema 校验、单位换算、与原文核对页码 | 逐项或整批确认 |
| B. 物料表（新） | ERP 导出的物料表、采购清单（Excel，几百上千行） | 认列（编码、名称、规格、厂商、型号）、分品类、查重、找对应的公共库条目 | 去重、建“待补数据”清单 | 确认分类与对应关系 |
| C. 三维模型（新） | 企业自己的 STEP 模型（自制件为主） | 判断零件类型、给端口命名的建议 | **从几何上量**：外形包络、质量（按材料）、轴段直径与长度、孔位与分度圆；用本书修好的检查几何先查模型有效 | 确认端口与关键尺寸 |

三条通道的结果都进企业库，同一套写入规则：每个值有依据（资料 id + 页码原文，或“从模型测量”+ 模型文件的 SHA-256，或人工录入 + 录入人）；缺数据不写；校验遇缺数据为“待确认”。

### 品类扩充（schema 改动，单独 PR + ADR）

现有 6 类：伺服电机、减速器、驱动器、轴承、连接件、紧固件。缝纫机要加：

1. **自制件** `custom_part`：企业自己设计加工的零件（轴、曲柄、凸轮、支架）；以三维模型为主要依据，参数按测量结果。
2. **通用外购件** `purchased_part`：同步带与带轮、电磁铁、传感器、机针、旋梭等——必填只有外形包络与厂商型号，关键参数按需填，先能进 BOM、能做干涉检查。
3. **步进电机** `stepper_motor`：自动缝纫设备常用。

轴承已有品类，补数据即可。

### 库的完整度报告（新）

一张表：每个零件缺哪些数据、缺了会影响哪项校验（例如缺法兰孔位 → C3 待确认），按影响面排序，告诉企业先补哪几个。

### 示范缝纫机企业（虚构）

- 一份虚构的物料表（Excel）：按 JUKI DDL-9000C 一类直驱平缝机的结构列约 40 行（伺服电机、驱动器、轴承、同步带、电磁铁、传感器、机针、旋梭、上轴、曲柄、凸轮、紧固件等），标明“示范数据，非真实企业”。
- 自制件的三维模型由我们按问渠《机械设计》第 33.11 节的上轴 LS-101 等在 FreeCAD 里建，走通道 C。
- 外购件参数只来自登记过、核过条款的公开目录（ADR-0040：只收参数与接口尺寸、逐份登记官方下载地址、不转存文档与 CAD）；轴承目录（NSK 或 NTN）先核条款再登记，不允许就不收，在完整度报告里列为缺数据。

### 施工顺序与验收

1. 0.3a 验收（Eddie）。
2. ADR + schema PR：三个新品类（freecad-ai-parts）。
3. 通道 B（物料表）→ 完整度报告。
4. 通道 C（三维模型测量）。
5. 通道 A 成批抽取。
6. 示范缝纫机企业：从虚构物料表出发，用三条通道建库，记下用时。

- 自制件 LS-101 的三维模型测出的轴段直径、长度与《机械设计》第 33.11 节的数据一致（Ø10×22、Ø12×10、Ø16×215、Ø12×10、Ø10×40）。


1. **回放示例**（不要密钥、不花钱）：工具栏“AI 设计零件…” → “载入示例：平缝机上轴” → “开始设计”。约 5 分钟后：

4. **0.3b 企业建库**（还没验收）：照 freecad-ai-parts 的 `examples/enterprise-lockstitch/README.md` 看示范企业的物料表结果、完整度报告和主轴选型。

## 0.3d 关节空心轴与“减重 3 轮”（2026-11-19 加，Eddie 确认“好”；2026-11-22 验收通过）

freecad-ai-parts 这一段做完的（ADR-0100 42.2 之五、之六，42.5 第 6、7 步）：

- **减重另给 3 轮**：改到合格最多 4 轮；通过后再交回 AI 减重，最多 3 轮（减重的方案没通过可以接着改，算在 3 轮里），采用通过且最轻的一轮。
  平缝机上轴重录：采用第 4 轮，前 6201、后 6001、轴身 Ø12，0.284 kg（书中 LS-101 约 0.40 kg）。
- **关节空心轴**：面板“零件类型”可选“关节空心轴”，示例是协作机器人 J2 输出轴（结构与节拍照《机械设计》33.10）。AI 选轴承、内孔、法兰圆角；
  载荷由代码从机器人动力学算；刚度、强度、花键、疲劳、轴承寿命由代码校核。录制结果：6011、内孔 Ø41，0.830 kg（书中 6010、Ø50/Ø30，0.913 kg）。
  模型按设计建（花键段按大径圆柱、螺纹段按公称直径，贯通内孔），回读外圆逐段与内孔都一致；工程图加端视图标内孔；BOM 两个 6011。
- 回放更快：录制时把有限元和动力学的结果一起存下，回放不再现算（平缝机上轴回放从约 3 分钟降到几秒，生成模型另算）。

- `ai-wqcad.ps1`：固定到 dc7a17b（freecad-ai-parts #618 关节空心轴、#625 面板改单独窗口、#627 Windows 界面测试）；依赖加 mujoco（关节空心轴用真实 AI 时要现算动力学）。
