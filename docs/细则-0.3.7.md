# 问渠 CAD 0.3.7 细则：OCCT 补丁编进安装包（三本书发现的第二批）

状态：**施工中**（2026-11-25 起草；09:41 Eddie 确认“继续”）

## 一、起因

- 0.3.6 细则分三批（Eddie 11-24 定“按建议”）；第二批是“5 个 OCCT 补丁编进安装包”，另写细则——就是本细则。
- 这 5 个补丁 0.2b 已经移植到 OCCT 7.8.1、在 Eddie 电脑上用 `build-occt.ps1` 编过、验收过（2026-11-17）。但它们只在那台电脑上，**网站上下载的安装包里没有**。
- 后果：0.3.6-beta 出包时书里 61 个测试里第 6 章那组 3 个失败 2 个（离原点很远的零件做布尔运算，孔挖不掉），安装包是“放行”出去的。

## 二、决定（建议）

1. **OCCT 单独编一次、存起来反复用**：安装包工作流里加一个独立任务，只编受补丁影响的 3 个程序库（TKMath、TKGeomAlgo、TKTopAlgo），做法照搬 `build-occt.ps1`。编好按“补丁内容 + 依赖环境”存缓存；补丁不变，以后出包直接取，不再编。
   - 这个任务和 FreeCAD 编译同时开跑，不拉长出包时间（FreeCAD 本来要编几个小时，OCCT 预计 40–60 分钟）。
2. **出包时换库**：FreeCAD 装进环境以后、冒烟测试之前，用编好的 3 个程序库替换环境里原来的。FreeCAD 本身不重编（补丁不改头文件，0.2b 已验证）。
3. **先核版本再换**：环境里的 OCCT 必须正好是 7.8.1，不是就让出包失败（版本不对换库会出怪问题）。
4. **取消放行**：冒烟测试里第 6 章那组的例外删掉，16 组 61 个测试必须全过才出包。
5. **查副作用**：换库前、换库后各跑一次 FreeCAD 自带的 Part 测试（TestPartApp），换库后不许多出失败。
6. **许可（LGPL）**：OCCT 是 LGPL，改过的库随安装包发出去，要能拿到对应源码。补丁本来就在公开仓库；安装目录里加一份说明（OCCT 7.8.1 + 哪 5 个补丁、在哪里取）。
7. 版本号 **0.3.7-beta**；AI 工作台不变（还是 69fd2d6）。
