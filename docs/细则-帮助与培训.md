## 二、课程大纲（8 课，每课：学完能做什么 → 讲解 → 录屏 → 照做练习 + 检查点 → 3 道小测）

| 课 | 内容 | 互动 / 录屏 |
|---|---|---|
| 0 问渠 CAD 是什么 | 和 FreeCAD 的关系（基于 FreeCAD，不另写内核）；27 个补丁修了什么（按书的章，一句话一个）；AI 只起草、人确认；许可边界 | 动画：FreeCAD → 补丁 → 测试 → 问渠 CAD；总览视频 |
| 1 安装与第一次打开 | 三样工具、构建脚本、智能应用控制、经 pixi 启动、窗口标题、测试脚本怎么看 | 安装自检清单；PowerShell 每一步的画面用网页画（终端文字是真的输出） |
| 2 CAD 基础速成 | 零件设计：草图 → 约束 → 凸台 → 倒角 → 工程图，做一个缝纫机零件（压脚杆套环） | 录屏 3 段；练习附 STEP 答案 |
| 3 补丁带来的不同 | 检查几何（容差告警）、展开面（变形报告）、远离原点的布尔、STEP 读入…… 每个“以前会怎样、现在怎样” | 补丁前后对比（互动 ③）；样例 STEP 可下载 |
| 4 AI Parts 工作台 | 零件选型（轴承、螺钉、电机……）与确定性校验；密钥；国内自动用 DeepSeek；“未知”不算通过 | 录屏：选一个轴承、校验报告 |
| 5 企业零件库 | 三条进料通道建库；完整度报告；“先补”清单；示范缝纫机企业（虚构，标明） | 零件库浏览器（互动 ②）；录屏 |
| 6 AI 设计零件 | 平缝机上轴全过程：写需求原话 → 条件 → 每一轮校核 → AI 的问题 → 三维、工程图、BOM → 确认入企业库 | AI 设计回放（互动 ①）；录屏（回放示例） |
| 7 排错与维护 | 日志在哪、`diag-ai.ps1`、`tests-wqcad.ps1` 汇总怎么读、常见报错（智能应用控制、双击闪退、模板找不到、密钥没生效） | 常见问题表 |
