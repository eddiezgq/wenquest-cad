## 二、课程大纲（第二稿：Eddie 22:36“基础讲的太少，课程也太少，草图、建模、曲线、曲面、装配等内容不能少，AI 的东西太多了，一节课够了，要知道大家不熟悉 FreeCAD”）

**写给从没用过 FreeCAD 的人**：从界面和鼠标讲起，每课都是“学完能做什么 → 讲解 → 录屏（点哪里有黄圈）→ 跟着做 → 自己做 → 3 道小测”。
**一条主线贯穿全课程：一课一课做出平缝机 WQ-LS 的零件，最后装成挑线机构、出工程图**（尺寸取自 WQ-LS 设计，学员做的和真设计对得上；每课附答案模型）。

| 模块 | 课 | 内容 | 做出什么（WQ-LS 零件） |
|---|---|---|---|
| 一 入门 | 1 | 认识界面：工作台、模型树、属性、报告视图；鼠标导航（三种方式）；视图、选择；首选项、单位 | 打开 WQ-LS 整机，转着看 |
| | 2 | 文件与数据：新建、保存、撤销；导入导出 STEP / STL / DXF；文档里的对象和依赖关系 | 导出一个零件给别人 |
| 二 草图 | 3 | 草图入门：直线、圆、圆弧、矩形、多段线；构造线 | 压脚杆套环的截面 |
| | 4 | 约束：几何约束（水平、垂直、相切、重合、对称……）、尺寸约束、完全约束、过约束怎么查 | 针夹轮廓（完全约束） |
| | 5 | 草图技巧：镜像、阵列、修剪延伸、外部几何、表达式；电子表格驱动尺寸 | 曲柄轮廓（尺寸由表格驱动） |
| 三 零件建模 | 6 | 凸台、凹槽、旋转、挖槽旋转、孔（螺纹孔） | 针杆、曲柄销 |
| | 7 | 倒角、圆角、拔模、抽壳、加厚 | 曲柄（带平衡块） |
| | 8 | 扫掠、放样、螺旋（加法 / 减法） | 拉簧、面线导线钩 |
| | 9 | 阵列（线性、环形）、镜像、多重变换 | 手轮（辐条阵列） |
| | 10 | 基准面、基准轴、附着方式；参数化设计（表达式、电子表格、配置表） | 挑线杆（三个尺寸改一个全跟着变） |
| | 11 | Part 工作台：基本体、布尔运算（并、差、交）、偏移、截面；PartDesign 与 Part 什么时候用哪个 | 送布偏心轮 |
| 四 曲线与曲面 | 12 | 曲线：B 样条（控制点、阶次、连续性）、螺旋线、投影、相交线、草图到三维曲线 | 机壳外形的特征曲线 |
| | 13 | 曲面：Surface 工作台——填充、扫掠曲面、放样曲面、延伸、修剪；连续性（G0/G1/G2）怎么看（斑马纹、曲率） | 机壳机头的过渡曲面 |
| | 14 | 曲面到实体：缝合、成实体、加厚；检查几何（问渠 CAD 补丁：容差告警看得出缝合问题） | 机壳的一块外壳变成实体 |
| 五 装配 | 15 | 装配工作台（FreeCAD 1.x 自带）：插入零件、固定、关节（固定、旋转、滑动、圆柱、平面……）、自由度 | 曲柄滑块（曲柄、连杆、针杆） |
| | 16 | 运动与检查：驱动关节转动、看运动、测距离、干涉检查、爆炸视图 | 挑线四连杆装起来转一圈 |
| 六 工程图 | 17 | TechDraw：图框、投影视图、剖视、局部放大、尺寸 | 针杆零件图 |
| | 18 | 公差与技术要求：尺寸公差、形位公差、表面粗糙度、标题栏；物料清单；导出 PDF / DXF | 挑线机构装配图 + 物料清单 |
| 七 进阶 | 19 | 有限元（FEM 工作台 + CalculiX）：材料、约束、载荷、网格、求解、看结果 | 曲柄在 5000 r/min 下的应力 |
