## 二、6 条怎么改

代码都在 freecad-ai-parts 的 DAE 内核（`analysis/mbd/dae`）。每条都先写 ADR，再做两个 PR：先改 schema（只加可选字段，旧模型照样能读），再写实现和测试。

### 1. 高速转动构件的精度（线索第 2 条）

| 项 | 内容 |
|---|---|
| 问题 | 重陀螺自转 200 rad/s，每转一圈要重选一次独立坐标，轴向误差 9.4e-3 rad，比直接积分欧拉参数差五个量级；能量核查判不通过但不说原因 |
| 改法 | 转动的独立速度改用构件自身系的角速度，姿态按转动增量更新（不再拿欧拉参数分量当独立坐标），归一约束不参与分块。改的是积分时用的坐标，不改模型格式 |
| schema | 不改（只加 `analysis.rotation_update` 可选开关，缺省用新方法，旧方法留作对照） |
| 验证 | 书第 3 章两种规则进动 1 s、rtol 1e-8：轴向误差 ≤ 1e-6 rad，能量核查通过 |

### 2. HHT 积分器在有转动或约束时只有一阶（线索第 10 条）

| 项 | 内容 |
|---|---|
| 问题 | 缺省 α = −0.1 时，自由刚体、转动副空转的收敛阶只有 1.0，10 s 后姿态错 15°、动能少 4 % |
| 改法 | 按 Negrut 等（2007）核对 α 加权作用在哪些力上（惯性力、外力、约束反力、归一约束乘子），把两时刻的乘子、加速度对齐；修好之前报告写明“有转动构件时 HHT 精度一阶”；能量核查阈值随积分器精度档调整 |
| schema | 不改 |
| 验证 | 自由刚体 10 s、缺省容差：姿态误差 ≤ 1e-3 rad；五档容差的实测阶 ≥ 1.8。书里四个模型做回归 |

### 3. 移动副摩擦考虑反力矩（导轨长度，线索第 28 条）

| 项 | 内容 |
|---|---|
| 问题 | 移动副的摩擦只按横向力算，不计反力矩引起的两端接触（抽屉效应）；曲柄滑块在 μ = 0.9 时力矩少算 6 倍，自锁的 μ 由 0.96 变成 1.61 |
| 改法 | 移动副加导轨接触长度；法向力取 \|F⊥\| + 2\|M⊥\|/l。转动副可加销长度，弯矩换成两端接触力 |
| schema | `joints[].friction.guide_length_mm`（移动副）、`joints[].friction.pin_length_mm`（转动副），可选；不给时照旧并在局限里写明 |
| 验证 | 书第 20 章：抽屉 μ = 0.25 刚好推不动（加速度 0）；曲柄滑块 μ = 0.5、θ = 90° 为 11.33 N·m |

### 4. 齿轮时变啮合刚度（线索第 34 条）

| 项 | 内容 |
|---|---|
| 问题 | 齿轮啮合力元是常值刚度，没有单齿、双齿交替，传动误差波动算出来是 0（应为 21.5 μm），齿轮箱振动、噪声、拍齿全算不出 |
| 改法 | 由齿数、模数、齿宽、压力角算重合度，按啮合位置切换一对、两对齿的刚度（先用矩形波；单齿刚度可由用户给，或按 ISO 6336 估）；输出传动误差及啮合频率分量；有侧隙时记录齿面分离 |
| schema | 齿轮啮合力元加 `teeth_1`、`teeth_2`、`module_mm`、`face_width_mm`、`pressure_angle_deg`、`single_tooth_stiffness_n_per_mm`（可选，缺了不估、按常值刚度并写明） |
| 验证 | 书第 23 章：静态传动误差峰峰 = F/(2k₁)；转速扫描的共振峰位置与书一致（± 0.04 f_n） |

### 5. 丝杠、蜗杆的效率与自锁（线索第 36 条）

| 项 | 内容 |
|---|---|
| 问题 | 丝杠、蜗杆、齿轮系都是无损、可逆的传动比约束：效率恒为 1，断电时负载能把丝杠、蜗杆倒拖到 −4163 rad/s；常值摩擦选项补不上（20 N 多算 483 %、2000 N 少算 48 %） |
| 改法 | 传动件带导程、中径、牙型角（或压力角）、摩擦系数，按斜面模型让摩擦力与约束反力成正比；报正驱、反驱效率与是否自锁；齿轮每对啮合给效率 |
| schema | 传动比约束（丝杠、蜗杆、齿轮对）加 `lead_mm`、`pitch_diameter_mm`、`thread_angle_deg`、`friction_coefficient`、`efficiency`（齿轮），都是可选；不给时照旧（无损）并在局限里写明 |
| 验证 | 书第 24 章：Tr16×4、μ 0.1、500 N，100 rad/s 举升中断电，17.72 ms 停转后锁住；滚珠丝杠（μ 0.005）35.91 ms 停转后反转，角加速度 −2484.6 rad/s² |

### 6. 控制器的采样与延迟（线索第 44 条）

| 项 | 内容 |
|---|---|
| 问题 | FMU 控制器在采样时刻读测量、立即输出；连续 PID 没有采样。真实控制器至少晚一拍，在问渠里调稳的增益上机可能发散（转台 PD 例：问渠稳定，加一拍延迟发散） |
| 改法 | FMU 与 PID 控制器加采样周期、输出延迟 n 拍、执行器一阶滞后 τ_a、限幅；结果里报 ωₙT_s（或闭环谱半径），超过临界值时提示 |
| schema | `controllers[].sample_time_s`、`delay_steps`、`actuator_lag_s`、`output_limit`，可选；缺省 0 拍延迟（与现在一致）但报告写明“未计延迟” |
| 验证 | 书第 31 章转台：延迟 0 拍稳定、1 拍发散；ζ = 1 时临界 ωₙT_s 为 0.426 |

## 三、规矩

- 每条先写 ADR（改了什么字段、单位、缺省值、旧模型怎么办），schema PR 单独提、不带实现代码；实现 PR 在 schema 合并后提。分支 `m47/<简述>`，提交信息 `M47: …`。
- 新字段一律**可选**：旧模型、旧报告照样能读能算；缺数据不估值，结果照旧并在局限里写明“没算 X”。
- 每条的验证题照书里的做成回归测试；做不到的不硬凑，写回本细则第五节告诉 Eddie。
- 新中文提示配英文；FreeCAD 面板里能填这些新字段（建模面板加对应输入项）。
- 不开租用 GPU；安装包只在全部合并后打一次。
