### B. 问渠有限元（freecad-ai-parts `analysis/fea`）

**B1 七点三角形积分权重对调（线索第 19 条，错误）**
- 改法：`solve.py` 里 `_W1`、`_W2` 对换，让 a₁ = (6 − √15)/21 配 (155 − √15)/2400。
- 验证题：
  - 逐单项式精确度：x^a·y^b 在 a + b ≤ 5 时与解析值相差 < 1e-14，a + b = 6 时不精确；
  - 单向受压立方块：应力处处 10.000 MPa（原来最大 10.25）；
  - 厚壁圆筒：内壁应力偏差 ≤ 0.05%（原来 0.65%）。
- 影响：所有面载荷、弹性支承的节点面积、面热流，有限元的数值会变。凡是测试里写死了旧数值的，**逐个说明原因再改**；`tests/golden/` 是选型校验，不涉及有限元，不动。

**B2 对称面不该算约束面（第 35 条，错误）**
- 改法：评定最大应力时排除的“约束面”只包括全固定、多分量被限的支承；对称面、只限法向的滑动支承不排除。评定值和全部节点峰值相差大、而峰值落在被排除面上时，报告里写明。
- 验证题：书里的八分之一带孔厚板，评定最大应力与三维加密收敛值相差 ≤ 2%，位置在 x = 0 的孔边。

**B3 面引用不稳定（第 40 条，错误）**
- 改法：算例里每个被引用的面另存“面签名”（类型、法向、面积、中心）和 STEP 的 SHA-256。STEP 变了就按签名重新匹配；匹配不唯一或找不到时，拒绝计算并请人确认，不再静默沿用面号。
- **算例文件多了字段，按 freecad-ai-parts 规矩：先单独一个 PR 改 schema 并写 ADR，再一个 PR 改代码。** 旧算例没有签名时照旧算，报告里标“面引用未核对”。
- 验证题：书里五种几何修改，5 / 5 匹配正确或拒绝。

**B4 报告解释的反向核对（第 42 条第 1 款，错误）**
- 改法：AI 写的句子点名某项核查并下结论时，正反两个方向都和实际结果比对（现在只拦“把没过说成过”，不拦“把过说成没过”）。
- 第 42 条其余 5 款是建议，放第三批。
- 验证题：书里原型 `ch49_claims` 的反向用例全部退回。

### C. 问渠多体动力学（freecad-ai-parts `analysis/mbd`）

**C1 运动副写成（构件, 地面）时反力方向反了（第 17 条）**
- 改法：`dae/solve.py` 第 178 行，body_j 为地面时直接按 body_i 报出，不取反。
- 验证题：同一质点单摆两种写法，“作用在摆上的力”逐点相同、指向支点（0 → +29.43 N）。

**C2 丝杠、蜗杆受载时约束失效却报正常（第 37 条，严重）**
- 改法：`mechanisms.py` 的丝杠、蜗杆、齿轮系、带传动的传动比耦合，改用固定肌腱 + 肌腱等式（关节等式的正则项没乘传动比平方，这是错的根源）。结果里加“各约束最大偏差”，超阈值不给 ok。
- 验证题：
  - 丝杠螺母受 200 N，偏差 ≤ 0.2 mm（原来 954 mm）；
  - 蜗轮受 30 N·m，落后 ≤ 1°（原来 15.3°）；
  - 稳态偏差和公式 r ≈ (R/A)·a₀/k_ref 相差 ≤ 10%。

**C3 把“锁死”当“冗余”，自由度核查恒为通过（第 11 条）**
- 改法：
  - 先只用运动副约束判秩，得出结构自由度；驱动数和它不相等就报“锁死”或“欠驱动”，不再删真约束；
  - 最小非零奇异值低于阈值时，报出对应的约束组合和“偏差约 X mm”，由用户确认按冗余还是锁死处理；
  - 自由度核查改成比较两个独立算出的数。
- 验证题：双平行四边形，第三根曲柄支点偏 ε = 1 mm 报锁死；ε = 1e-6 mm 报“近冗余，按冗余处理”。

**C4 静平衡不判稳定性（第 21 条）**
- 改法：静平衡算完，用已有的线性化（约化刚度）判稳定，结果写进报告；不稳定时提示，“先静后动”从不稳定平衡出发也提示。实特征值不再标成“频率”，注明“非振动模态”。
- 验证题：倒立杆加扭簧（κ = 0，从 5° 出发）报“不稳定平衡”；书里四杆机构的 4 个不稳定起点全部报出。
