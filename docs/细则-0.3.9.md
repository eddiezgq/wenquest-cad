### 2. 结果可信（7 条）

| 线索 | 问题 | 改法 | 验证 |
|---|---|---|---|
| 8 | MuJoCo 路线闭环约束耗能（力矩驱动起步少转 18 %），没有能量核查 | 0.3.8 已报闭环拉开；再加能量平衡核查（输入功 − 机械能变化 − 阻尼摩擦耗散），超阈值判“待确认”；力矩驱动 / 无驱动的闭环机构缺省 τ 收紧到 2–3 倍步长 | 书里算例终了转角 36.230 rad（差 ≤ 1 %），或报能量核查不通过 |
| 71 | 平缝机 5000 rpm：MuJoCo 路线峰值 3.94 N·m（精确 2.650），恒速一转平均功率 367 W（应为 0）；存档报告与当前代码不一致 | 一转时间与约束时间常数之比小于 50 时改走 DAE 内核（给定运动的闭环机构力矩由 DAE 算），MuJoCo 只出动画；输出跟踪误差与一转平均功率并设阈值；连带查 0.3.8 发现的 2400 rpm 10 % 误差 | 5000 rpm 峰值 2.650 N·m（差 ≤ 1 %） |
| 19 | 给定运动的驱动力矩在加速度跳变处过冲，峰值随记录频率变（+10 %） | 峰值、功率峰值用给定轨迹的精确逆动力学；t = 0 的力矩用下一点；报告写峰值时刻与记录频率 | 书里三关节例 100 Hz 与 1000 Hz 峰值都与精确值差 ≤ 1 % |
| 9 | “匀速”驱动瞬间起步，起步冲击进了选型需求（+13 %） | 匀速驱动加平滑起步；峰值、均方根剔除起步段（或单列）；需求注明取值区间 | 剔除起步段后峰值在 0.623 N·m 的 3 % 以内、转速不超过 600 rpm |
| 26 | 冗余反力的“完整”标记只看本运动副是否删行；衬套力不输出 | 用全部约束雅可比的零空间判每个分量是否唯一，报自平衡力系；输出衬套、弹簧力元的力；刚性副与衬套并用时提示 | 平行四边形 A1–A3 标不唯一、报 (e, −2, 1) |
| 72 | 闭环机构“最大等效惯量”取锁住其他关节的对角元（偏大 4.8 倍） | 单自由度闭环机构按 J(θ) = Σ m\|∂r/∂θ\|² + I(∂φ/∂θ)² 输出范围与一转平均；开链照旧但写明定义 | 平缝机 J 在 2.52e-6–1.86e-5、平均 1.01e-5 kg·m² |
| 5 | 协作臂工况只算“往下放”，“往上抬”峰值大 34 % | 按往返（去 + 停 + 回）算或两个方向取包络，报告写明 | 肩关节峰值取 124.1 N·m（往上抬） |

## 四、规矩

- freecad-ai-parts：一条线索一个 PR，分支 `m46/<简述>`，提交信息 `M46: ...`；验证题做成回归测试；`tests/golden/` 不动；新中文提示配英文（en.json 按字典序插入）；核查项的 limit 用数。
